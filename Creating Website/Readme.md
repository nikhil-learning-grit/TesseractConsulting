# Read Me 

#### Remote Deployment Configuration
1. The code for the website was written in VS code. For making it easier to sync the **.php** pages of the website, sftp protocol was used to connect the code folder with the VPS server, so that the files can be synced and sent to the server reducing the manual effort of transferring them each time the code is edited. 
2. For this, the sftp extension by Natizyskunk was added to the VS code editor. Additionally, a file named "sftp.json" was created in .vscode folder in the root directory of the website.
